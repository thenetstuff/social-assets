# theNetStuff social assets

Finished graphics for theNetStuff social posts (Facebook, Instagram, LinkedIn, Google Business Profile).

This repo is public so the scheduling tool can fetch images by URL. Only put finished, approved-for-posting graphics here. No client photos without the client's permission, and nothing private.

Folders are by month (`2026-11/`). Raw URL pattern:
`https://raw.githubusercontent.com/thenetstuff/social-assets/main/<folder>/<file>.png`
